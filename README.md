# Vehicle Management System 🚗

A standalone Java application developed using **Core Java, Hibernate ORM, Maven, and MySQL** to manage vehicle information, insurance details, and service records.

## Features
- Add and manage vehicle details
- Associate insurance records with vehicles using `@OneToOne`
- Maintain multiple service records using `@OneToMany`
- Perform CRUD operations: Insert, Retrieve, Update, and Delete
- Manage database transactions using Hibernate
- Handle errors using custom exceptions
- Interactive console-based menu using Java `Scanner` and `switch`
- Manage database persistence using Hibernate ORM

## Technologies Used
- Java 17+
- Hibernate ORM
- MySQL
- Maven
- Eclipse IDE

## Project Purpose
This project demonstrates practical implementation of Hibernate entity relationships, database operations, session and transaction management, and exception handling in a standalone Java application.
